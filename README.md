## Publicação no GitHub Pages

1. Crie um repositório público chamado `astrion-brand`.
2. Envie todo o conteúdo deste pacote para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve.

A página deverá ficar em:

`https://wellingtonmendesmendes.github.io/astrion-brand/`

Depois da publicação, troque os caminhos relativos da assinatura por URLs absolutas.
